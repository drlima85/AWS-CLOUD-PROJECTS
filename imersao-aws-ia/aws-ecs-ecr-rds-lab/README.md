# Imersão AWS & IA — Dia 1: ECS, ECR e RDS

> Desafio prático guiado, realizado durante o evento **Imersão AWS & IA**,
> conduzido por [Henrylle Maia](https://www.linkedin.com/in/henrylle/).

------------------------------------------------------------------------

## 🎯 Objetivo do Dia 1

Iniciar a migração de uma aplicação para uma arquitetura containerizada
na AWS, utilizando o **Amazon ECS** como orquestrador de containers e o
**Amazon RDS** como banco de dados gerenciado.

------------------------------------------------------------------------

## 🚀 Atividades Realizadas

- Criação de um cluster no **Amazon ECS**, o principal serviço de
  gerenciamento de containers da AWS
- Provisionamento de banco de dados no **Amazon RDS**
- Execução das migrations para criar a estrutura relacional do banco
- Configuração de **Security Groups** para controlar o acesso entre os
  componentes
- Início do desmembramento da aplicação para rodar na nuvem
- Build da imagem Docker da aplicação e envio para o **Amazon ECR**
  (Elastic Container Registry)
- Deploy da aplicação no ECS via script
- Configuração do processo de deploy para permitir **rollback** em caso
  de falha
- Troubleshooting de problemas durante o processo, com apoio de IA

------------------------------------------------------------------------

## ☁️ Tecnologias

Amazon ECS · Amazon ECR · Amazon RDS · Docker · Security Groups (AWS) ·
Scripts de deploy

------------------------------------------------------------------------

## 🎯 Competências Demonstradas

- Containerização de aplicações com Docker
- Orquestração de containers com Amazon ECS
- Gestão de imagens de container com Amazon ECR
- Provisionamento e configuração de banco de dados gerenciado (RDS)
- Deploy com estratégia de rollback
