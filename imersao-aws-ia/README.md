# Imersão AWS & IA

> Série de desafios práticos realizados durante o evento **Imersão AWS & IA**,
> conduzido por [Henrylle Maia](https://www.linkedin.com/in/henrylle/).

Cada dia do evento propôs um desafio prático guiado, evoluindo a mesma
aplicação em direção a uma arquitetura containerizada, altamente
disponível e protegida na AWS. Projeto concluído em 3 dias.

## 📂 Dias / Desafios

### [Dia 1 — ECS, ECR e RDS](./aws-ecs-ecr-rds-lab)
Criação de cluster ECS, provisionamento de banco de dados no RDS,
containerização da aplicação com Docker/ECR e primeiro deploy com
suporte a rollback.

### [Dia 2 — Alta Disponibilidade, ALB e CI/CD](./aws-ha-cicd-alb-lab)
Aplicação Node.js/React em Alta Disponibilidade, deploy sem downtime,
Application Load Balancer + Target Group, pipeline CI/CD acionado por
push no branch `main`, domínio personalizado com HTTPS.

### [Dia 3 — CloudFront, WAF e Segurança de Borda](./aws-cloudfront-waf-lab)
CloudFront como CDN à frente do Load Balancer, hardening do ALB via
Security Group e AWS WAF para mitigar ataques na borda.

------------------------------------------------------------------------

## ☁️ Tecnologias (visão geral)

Amazon ECS · Amazon ECR · Amazon RDS · Docker · Application Load
Balancer · Target Group · CI/CD · Amazon CloudFront · AWS WAF ·
Security Groups (AWS) · HTTPS / DNS

## 🎯 Competências Demonstradas

- Containerização e orquestração de aplicações (Docker + ECS)
- Alta Disponibilidade e deploy sem downtime
- CI/CD acionado por push em branch
- CDN e segurança de borda (CloudFront + WAF)
- Hardening de rede (Security Groups, ALB)
