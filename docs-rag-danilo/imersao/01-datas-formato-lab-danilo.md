# Laboratório Danilo — Sobre este projeto

Este repositório é um laboratório pessoal de estudos focado em **Inteligência Artificial generativa** e **Amazon Bedrock**, mantido por Danilo Lima.

O objetivo é documentar experimentos, projetos práticos e anotações técnicas construídos ao longo da jornada de aprendizado com IA na AWS.

## Foco principal

- Amazon Bedrock e modelos de linguagem (LLMs)
- Integração de IA generativa com serviços AWS
- RAG (Retrieval-Augmented Generation) com Knowledge Bases
- Agentes de IA e orquestração multi-agentes
- Guardrails, cache de prompt e boas práticas de produção

## Formato

Os estudos são organizados em scripts práticos, anotações por módulo e projetos incrementais — do primeiro `converse` via CLI até assistentes com RAG, tools e guardrails.

Tudo documentado de forma incremental, refletindo a evolução real dos estudos.
