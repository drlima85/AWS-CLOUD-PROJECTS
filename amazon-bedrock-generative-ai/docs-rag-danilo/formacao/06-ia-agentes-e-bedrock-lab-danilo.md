# Laboratório Danilo — IA, agentes e Amazon Bedrock

Este é o módulo principal deste laboratório. O foco está em IA generativa na AWS, com ênfase no Amazon Bedrock, agentes de IA e integração prática com serviços AWS.

## AWS & IA

- Consumindo MCP Servers
- Instalando e configurando o Amazon Q CLI
- Contexto e Rules
- Containerização com IA
- Criando infraestrutura com linguagem natural

## Agentes de IA & Multi-Agentic (novo módulo)

- Criando agentes de IA na prática
- Multi-agentes aplicados a projetos reais
- Orquestração do trabalho entre agentes
- MCP Server especializado por agente
- Aplicação em projeto prático
- Trabalhando com worktree

## Amazon Bedrock

- LLMs disponíveis no Bedrock (Claude, Titan, Llama, Mistral, etc.)
- Tokens: input, output e modelo de cobrança
- Estrutura de prompt: system, tools, messages
- Técnicas de prompt: zero-shot, few-shot, chain-of-thought
- Parâmetros de inferência: temperatura, top_p, max_tokens
- Streaming de respostas
- Cache de prompt
- RAG com Knowledge Base e banco vetorial
- Guardrails: filtros de conteúdo e proteção de PII
- Avaliação de modelos
- Projeto prático via CLI
- Projeto prático via SDK (Node.js)

## N8N (novo módulo)

- Queue Mode (usando ECS)
