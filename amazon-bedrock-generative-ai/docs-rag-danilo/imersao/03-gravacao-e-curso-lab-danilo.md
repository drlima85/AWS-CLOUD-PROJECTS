# Laboratório Danilo — Estrutura do repositório

O repositório está organizado de forma a separar scripts práticos, documentação de estudos e material de referência.

## Estrutura de pastas

```
colorado/
├── scripts/               # Projetos práticos de cada etapa de estudo
│   └── sdk-node/          # Versões em Node.js (v4 a v9)
├── docs-rag-danilo/       # Documentação deste laboratório (usado no Knowledge Base)
│   ├── imersao/           # Visão geral, objetivos e contexto do lab
│   └── formacao/          # Conteúdo técnico por tema (computação, IA, rede, etc.)
├── docs-rag/              # Documentos originais de referência
├── docs-rag-v2/           # Segunda versão dos documentos de referência
├── material-alunos/       # Material de apoio (HTML e PDF)
└── apoio/                 # Anotações e referências técnicas
```

## Progresso dos estudos

Os scripts em `scripts/` seguem uma progressão incremental:

- Primeiros testes com `converse` via CLI
- Streaming e cache de prompt
- RAG com Knowledge Base
- Guardrails
- Projeto com tools e agentes
