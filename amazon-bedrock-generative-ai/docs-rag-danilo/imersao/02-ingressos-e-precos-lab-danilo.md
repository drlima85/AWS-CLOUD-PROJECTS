# Laboratório Danilo — Objetivos de aprendizado

Este laboratório tem como meta construir domínio prático sobre IA generativa e Amazon Bedrock, passando por todos os níveis: fundamentos, integração com AWS, e projetos reais.

## Objetivos por nível

### Nível 1 — Fundamentos de LLMs e Bedrock

- Entender o que são LLMs e como funcionam tokens (input, output, cobrança)
- Estruturar prompts: system, tools, messages
- Técnicas: zero-shot, few-shot, chain-of-thought
- Parâmetros de inferência: temperatura, top_p, max_tokens
- Realizar o primeiro `converse` via AWS CLI

### Nível 2 — Integração e recursos avançados

- Streaming de respostas
- Cache de prompt
- Construção de RAG com Knowledge Base do Bedrock
- Banco vetorial com OpenSearch Serverless
- Guardrails: filtros de conteúdo e PII

### Nível 3 — Projetos práticos e agentes

- Projeto completo via CLI (sem SDK)
- Projeto completo via SDK (Node.js)
- Agentes de IA com Action Groups e Lambda
- Multi-agentes aplicados a problemas reais
- MCP Servers integrados a agentes especializados
