# Amazon Bedrock | Generative AI Labs

Laboratório prático de Inteligência Artificial Generativa na AWS, desenvolvido durante meus estudos da Formação AWS, com foco na implementação e compreensão dos recursos do Amazon Bedrock.

## Objetivos

- Explorar modelos de linguagem no Amazon Bedrock.
- Realizar chamadas de inferência utilizando AWS CLI e SDK para Node.js.
- Compreender o funcionamento de Tool Use.
- Implementar e avaliar estratégias de RAG.
- Explorar Amazon Bedrock Knowledge Bases e S3 Vectors.
- Aplicar Guardrails para controle e segurança das respostas.

## Tecnologias

- Amazon Bedrock
- AWS CLI
- AWS SDK for JavaScript (Node.js)
- Amazon Bedrock Knowledge Bases
- Amazon S3 Vectors
- Amazon Bedrock Guardrails
- Kiro CLI e AWS Documentation MCP Server

## Evolução do laboratório

| Etapa | Conteúdo |
|---|---|
| 1 | Primeiras chamadas ao Bedrock via AWS CLI |
| 2 | Mensagens e prompts personalizados |
| 3 | Conversação interativa |
| 4 | Integração com ferramentas (Tool Use) |
| 5 | Recuperação de informações com RAG |
| 6 | Knowledge Bases e estratégias de recuperação |
| 7 | Guardrails e testes de segurança |

## Segurança e boas práticas

Os laboratórios utilizam configurações locais e variáveis de ambiente para integração com a AWS.

Credenciais, arquivos de configuração sensíveis, logs e dependências locais não devem ser publicados no repositório.
